# DwarPal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A merchant-side gateway that makes a Razorpay merchant sellable to AI buyer agents: agent-readable catalog, ACP-shaped checkout API, deterministic policy gate, per-agent spend mandates, Razorpay test-mode Payment Links with failure recovery, hash-chained ledger, bounded LLM cross-sell and enrichment, demo buyer agent, batch metrics, merchant dashboard.

**Architecture:** One Python package `dwarpal/` with one FastAPI process and one SQLite file. Money is integer paise. The gate is a pure function; the LLM only proposes (catalog metadata, offers, the demo buyer's carts) behind deterministic validation or merchant approval. Every store takes an injected `clock` so tests are deterministic and offline. `FakePayments` and fake LLMs stand in for Razorpay and the model in tests and metrics.

**Tech Stack:** Python 3.11+ (3.14 on the dev machine), FastAPI, Jinja2, pydantic v2, stdlib sqlite3, `razorpay` SDK, `openai` client (any OpenAI-compatible endpoint), httpx, pytest.

**Spec:** `docs/superpowers/specs/2026-09-03-dwarpal-design.md`

## Global Constraints

- Python `>=3.11`; run everything from the repo root with `python -m ...`.
- Money is integer paise everywhere; `bool` is never accepted as an int (`type(x) is int`).
- Currency is `INR` only.
- The Razorpay adapter refuses any key id that does not start with `rzp_test_`; every SDK call has a 10 s timeout.
- Tests never touch the network: `FakePayments`, `FakeLLM`, fixed clock.
- Every store and service takes `clock: Callable[[], int]` (unix seconds); default `lambda: int(time.time())`.
- Ledger: `hash = sha256(prev_hash + canonical_json({seq,id,ts,type,actor,session_id,payload}))`, genesis prev hash is 64 zeros, canonical JSON is `json.dumps(obj, sort_keys=True, separators=(",", ":"), ensure_ascii=False)`.
- Gate rule ids are exactly: `G00_WELL_FORMED, G01_AGENT_ACTIVE, G02_MANDATE_ACTIVE, G03_ITEMS_KNOWN, G04_IN_STOCK, G05_SKU_NOT_BLOCKED, G06_MERCHANT_CATEGORY, G07_QTY_PER_LINE, G08_ORDER_MAX, G09_MANDATE_CATEGORY, G10_PER_TXN_CAP, G11_DAILY_CAP, G12_TOTAL_CAP, G13_SESSION_STATE, G99_GATE_ERROR`; an ALLOW decision has `rule_id == "ALLOW"`.
- Session statuses are exactly: `not_ready_for_payment, ready_for_payment, payment_pending, completed, canceled`.
- Id prefixes: `prod_, enr_, agt_, mnd_, cs_, rsv_, lp_, evt_` + 12 url-safe chars from `secrets.token_urlsafe(9)`.
- API version string: `2026-09-03`. Merchant id `trail-and-turf`, name `Trail & Turf`.
- Commit after every task with the message given; no co-author trailer is required by the user, but the session's attribution rule applies: end commit messages with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` and the session link line.

from dataclasses import dataclass

@dataclass
class Settings:
    db_path: str = "dwarpal.db"
    merchant_id: str = "trail-and-turf"
    merchant_name: str = "Trail & Turf"
    base_url: str = "http://127.0.0.1:8000"
    merchant_token: str = "dev-merchant-token"
    razorpay_key_id: str | None = None
    razorpay_key_secret: str | None = None
    razorpay_webhook_secret: str | None = None

    llm_api_key: str | None = None
    llm_model: str | None = None
    llm_timeout_s: int = 60
    fake_outcomes: str | None = None

    @classmethod
    def from_env(cls, env: Mapping[str, str] | None = None, dotenv: str | None = ".env") -> "Settings":
        merged: dict[str, str] = {}
        if dotenv and os.path.exists(dotenv):
            merged.update({k: v for k, v in dotenv_values(dotenv).items() if v is not None})
        merged.update(os.environ if env is None else env)
        g = lambda k, d=None: (merged.get(k) or d)
        return cls(
            db_path=g("DWARPAL_DB", "dwarpal.db"),
            merchant_id=g("MERCHANT_ID", "trail-and-turf"),
            merchant_name=g("MERCHANT_NAME", "Trail & Turf"),
            base_url=g("DWARPAL_BASE_URL", "http://127.0.0.1:8000").rstrip("/"),
            merchant_token=g("MERCHANT_TOKEN", "dev-merchant-token"),
            razorpay_key_id=g("RAZORPAY_KEY_ID"),
            razorpay_key_secret=g("RAZORPAY_KEY_SECRET"),
            razorpay_webhook_secret=g("RAZORPAY_WEBHOOK_SECRET"),
            llm_base_url=g("LLM_BASE_URL"),
            llm_api_key=g("LLM_API_KEY"),
            llm_model=g("LLM_MODEL"),
            llm_timeout_s=int(g("LLM_TIMEOUT_S", "60")),
            fake_outcomes=g("FAKE_OUTCOMES"),
        )

    @property

def require_paise(value, name: str = "amount") -> int:
    if type(value) is not int or value < 0:
        raise ValueError(f"{name} must be a non-negative integer number of paise, got {value!r}")
    return value


def rupees(paise: int) -> str:
    sign = "-" if paise < 0 else ""
    paise = abs(paise)
    whole, frac = divmod(paise, 100)
    return f"{sign}INR {whole:,}.{frac:02d}"

```python
from __future__ import annotations
import json
import sqlite3
from contextlib import contextmanager
from importlib import resources

def connect(path: str) -> sqlite3.Connection:
    conn = sqlite3.connect(path, check_same_thread=False, isolation_level=None)
    conn.row_factory = sqlite3.Row
    if path != ":memory:":
        conn.execute("PRAGMA journal_mode=WAL")
    conn.execute("PRAGMA foreign_keys=ON")
    return conn

def init_db(conn: sqlite3.Connection) -> None:
    schema = resources.files("dwarpal").joinpath("schema.sql").read_text(encoding="utf-8")
    conn.executescript(schema)

@contextmanager
def tx(conn: sqlite3.Connection):
    conn.execute("BEGIN")
    try:
        yield conn
    except BaseException:
        conn.execute("ROLLBACK")
        raise
    else:
        conn.execute("COMMIT")

def dumps(obj) -> str:
    return json.dumps(obj, ensure_ascii=False, sort_keys=True)

def loads(s):
    return json.loads(s) if s is not None else None

def now_utc_day_bounds(now: int) -> tuple[int, int]:
    start = now - (now % 86_400)
    return start, start + 86_400
```

`dwarpal/ledger.py`:
```python
from __future__ import annotations
import hashlib, json, time
from dataclasses import dataclass
from typing import Callable
from dwarpal.db import tx
from dwarpal.ids import new_id
from dwarpal.money import rupees

GENESIS = "0" * 64
TAMPER_FIELDS = ("amount_paise", "total_paise")


def canonical(obj) -> str:
    return json.dumps(obj, sort_keys=True, separators=(",", ":"), ensure_ascii=False)


def event_hash(prev_hash: str, body: dict) -> str:
    return hashlib.sha256((prev_hash + canonical(body)).encode("utf-8")).hexdigest()


@dataclass
class Event:
    seq: int; id: str; ts: int; type: str; actor: str; session_id: str | None
    payload: dict; prev_hash: str; hash: str

    def body(self) -> dict:
        return {"seq": self.seq, "id": self.id, "ts": self.ts, "type": self.type, "actor": self.actor,
                "session_id": self.session_id, "payload": self.payload}


@dataclass
class VerifyResult:
    ok: bool; count: int; bad_seq: int | None; detail: str


class Ledger:
    def __init__(self, conn, clock: Callable[[], int] | None = None):
        self.conn = conn
        self.clock = clock or (lambda: int(time.time()))

    def append(self, type: str, actor: str, payload: dict, session_id: str | None = None) -> Event:
        payload = json.loads(json.dumps(payload, ensure_ascii=False))  # normalise (tuples -> lists, etc.)
        with tx(self.conn):
            row = self.conn.execute("select seq, hash from ledger order by seq desc limit 1").fetchone()
            seq = (row["seq"] + 1) if row else 1
            prev = row["hash"] if row else GENESIS
            ev = Event(seq, new_id("evt"), self.clock(), type, actor, session_id, payload, prev, "")
            ev.hash = event_hash(prev, ev.body())
            self.conn.execute(
                "insert into ledger(seq,id,ts,type,actor,session_id,payload,prev_hash,hash) values (?,?,?,?,?,?,?,?,?)",
                (ev.seq, ev.id, ev.ts, ev.type, ev.actor, ev.session_id, canonical(ev.payload), ev.prev_hash, ev.hash))
        return ev
    # events(): select ordered by seq, optional session filter and limit; row -> Event with json.loads(payload)
    # head(): last hash or GENESIS
    # verify(): walk all rows; recompute; first mismatch or seq gap -> VerifyResult(False, n, seq, detail)
    # tamper(seq): load payload, multiply first TAMPER_FIELDS int by 10, write back without rehash; ValueError if none
    # receipt(session_id): markdown with heading, table of events (seq, type, actor, key facts), decision trail from the
    #   last gate.decision, payment attempts, "Head: <hash>" and "- Chain: verified" or "- Chain: BROKEN at seq N"
```
Implement `events`, `head`, `verify`, `tamper`, `receipt` exactly as the comments say; `receipt` must include every `checks[].rule` of the last `gate.decision` event for the session, and the literal strings `Chain: verified` / `Chain: BROKEN at seq`.

def reconcile(self, session_id: str) -> dict:
    row = self._load(session_id)
    if row is None or row["status"] != PENDING:
        return self._to_dict(row) if row else None
    try:
        res = self.payments.poll(row["link_id"])
    except PaymentsError as exc:
        self.ledger.append("provider.error", "reconciler", {"op": "poll", "error": str(exc)}, session_id)
        return self._to_dict(row)
    if res.order_id and not row["order_id"]:
        self._set(session_id, order_id=res.order_id)
    new = [a for a in res.attempts if not self._payment_seen(session_id, a.payment_id)]
    for a in new:
        self._record_payment(session_id, a, row["attempt"])
    captured = next((a for a in new if a.status == "captured"), None)
    if captured:
        return self._finish_paid(session_id, captured)
    failed_now = any(a.status == "failed" for a in new)
    expired = res.link_status == "expired" or (row["link_expire_at"] and self.clock() >= row["link_expire_at"])
    if failed_now or expired:
        return self._after_failed_attempt(self._load(session_id), "payment_failed" if failed_now else "link_expired")
    return self._to_dict(row)

`_after_failed_attempt(row, reason)`: if `row["attempt"] < 2`: decide RETRY (status PENDING, exclude_self=True), log; ALLOW → `_cancel_link_quietly(row)` → `create_link(... attempt=2, reference f"{sid}-2")` (on `PaymentsError`: log `provider.error`, `_abandon(row, "provider_error")`) → set attempt 2 + link fields → ledger `payment.retry` `{attempt: 2, reason}`, `payment.link.created`; DENY → `_abandon(row, f"retry denied by {d.rule_id}")`. `_abandon(row, reason)`: `_cancel_link_quietly` → release if open (ledger `mandate.released`) → status CANCELED → ledger `payment.abandoned` `{attempts: row.attempt, reason}` and `session.canceled` `{reason}`.
`_cancel_link_quietly(row)`: try `cancel_link` → ledger `payment.link.cancelled`; except `PaymentsError` → ledger `payment.link.cancel_failed`.
`_finish_paid(session_id, attempt)`: commit reservation (if open) → ledger `payment.captured` `{razorpay_payment_id, amount_paise, attempt}`, `mandate.committed` `{mandate_id, amount_paise}`, `session.completed` `{total_paise}` → status COMPLETED, `completed_at`.

def poll(self, link_id):
    try:
        link = self.client.payment_link.fetch(link_id, timeout=self.timeout_s)
        status = link.get("status", "created"); order_id = link.get("order_id")
        attempts = []
        for p in link.get("payments") or []:
            if p.get("status") == "captured":
                attempts.append(Attempt(p["payment_id"], "captured", int(p["amount"]), None, None))
        raw = []
        if order_id:
            raw = self.client.order.payments(order_id, timeout=self.timeout_s).get("items", [])
        else:
            raw = [p for p in self.client.payment.all({"count": 100}, timeout=self.timeout_s).get("items", [])
                   if (p.get("notes") or {}).get("session_id") == self._session_of(link)]
        seen = {a.payment_id for a in attempts}
        for p in raw:
            if p["id"] in seen: continue
            if p.get("status") == "captured":
                attempts.append(Attempt(p["id"], "captured", int(p["amount"]), None, None))
            elif p.get("status") == "failed":
                attempts.append(Attempt(p["id"], "failed", int(p["amount"]), p.get("error_code"), p.get("error_description")))
        return PollResult(status, order_id, attempts)
    except Exception as exc:  # razorpay.errors.* and network errors
        raise PaymentsError(f"razorpay poll failed: {type(exc).__name__}: {exc}") from exc
